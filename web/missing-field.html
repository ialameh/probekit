Access & permissions · Practical investigation guide

A Salesforce user cannot see a field

A missing field is a symptom. Start by checking whether the supplied exports contain a matching profile or direct permission-set grant.

Open the field-access checker →

Follow the evidence

  1. Choose a specific field and user. Use exact API names and the full username. The fictional example uses Account.Industry and jane.doe@example.com.
  2. Build the three queries. Open the dedicated checker. It provides user/profile, field-permission and permission-set-assignment queries. Run each in an approved query tool and export complete JSON or CSV results.
  3. Analyse the supplied evidence. Import all three exports and confirm their scope. Review matching grants, missing evidence and the suggested next checks.
  4. Check the remaining access layers. A field grant alone does not establish effective access. Check object and record access, permission-set-group muting, assignment activation or expiry, and the page or component displaying the field.

Try it first

Try “Try sample results” in the checker to explore the results without org access.

What this does not establish

Do not treat no matching grants as proof the field is absent or inaccessible. The result depends on the query, permissions and completeness of the exports.
