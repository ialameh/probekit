Investigate failed Salesforce background jobs

A job status narrows the question. Use its time window, class and error details to decide which evidence to inspect next.

Follow the evidence

  1. Set a focused time window. Open the async-job investigation. Choose days, optionally an Apex class and status, and a suitable result limit. For failures, use status Failed.
  2. Run and export the query. Use the API indicated on the step. Keep all columns, including Status, ExtendedStatus and NumberOfErrors. Export every result page.
  3. Read the counts and limits. Import the results. Review job types, statuses and error counts. If the query limit was reached, narrow the time window or class before drawing broader conclusions.
  4. Follow the evidence. Use exported timestamps and class names to identify relevant logs or related operations. Coordinate any retry with the owner of the job; this investigation does not rerun it.

What this does not establish

An empty export does not prove no jobs failed. A status or error count alone does not establish root cause, full business impact or whether a retry is safe.
