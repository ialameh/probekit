# Changelog

## 0.7.1

- Put current pack checks before save and report controls, with compact progress and a collapsible checklist.
- Added a completion report view and disabled saving until query steps exist.

## 0.7.0

- Added six guided investigation packs with saved check summaries and combined text/JSON reports.
- Kept partial, skipped and unstarted checks explicit, with reasons for skipped checks.
- Prevented mixing fictional samples and supplied exports in one pack.
- Added the MCP `analyse_investigation_pack` tool with shared validation and bounded inputs.
- Kept pack summaries in tab memory and invalidated saved checks when reopened or edited.

## 0.6.0

- Expanded the catalogue to 73 investigations, adding assignment expiry, frozen and dormant users, permission-set group status, user and permission-set licence capacity, approvals, queued tests, inactive record owners, missing values and stale records.
- Grouped browser browsing into six families and six task bundles, with ranked keyword and synonym search.
- Added MCP bundle discovery and replayable fictional examples, bringing the server to seven tools.
- Added scoped licence, approval-age, login-status and schedule findings and consistent numeric CSV handling.
- Displayed the release version on web pages from shared package metadata.

## 0.5.1

- Added separate problem-report and probe-request links throughout the web tools.
- Added contextual problem links beside investigation results and import errors.
- Report links include only the shipped investigation ID, never parameters or exports.
- Updated the field-access checker download to the versioned release archive.

## 0.5.0

- Added a starting guide and five-minute fictional comparison walkthrough.
- Added practical guides for missing fields, flow versions and failed jobs.
- Added local MCP connection-check and configuration commands.
- Added public bug and investigation-request forms with fictional-example guidance.

## 0.4.0

- Added an optional local MCP server for discovery, query planning, export analysis and comparison.
- Reused the browser investigation engine with exact-query validation and bounded imports.
- Added catalogue-wide MCP workflow tests and a stdio protocol integration test.

## 0.3.0

- Added a browser investigation workspace covering all 61 catalogue probes.
- Added dependent query steps, validated imports, scoped evidence summaries and fictional samples.
- Added two-export comparisons with duplicate counts and source fingerprints.
- Added text and JSON summary reports and a local preview command.
- Added catalogue-wide workflow tests and investigation-specific guidance.

## 0.2.0

- Added a free browser-based field-access checker with three read-only query steps.
- Added JSON and CSV result analysis for profile and direct permission-set grants.
- Added a fictional sample walkthrough and downloadable text findings reports.
- Added checks for incomplete exports, incompatible columns, mismatched users and fields.
- Added OrgParity branding, mobile layouts and local-processing privacy information.

## 0.1.0

- Released the CLI and searchable library of 61 Salesforce probes.
